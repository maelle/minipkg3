# minipkg3

The goal of minipkg3 is to aprender desarrollo de paquetes.

## Installation

You can install the development version of minipkg3 from
[GitHub](https://github.com/) with:

``` r

# install.packages("pak")
pak::pak("maelle/minipkg3")
```

## Example

This is a basic example which shows you how to solve a common problem:

``` r

library(minipkg3)
what_time()
#> [1] "Awww! Ahora son las 14:21!"
```
